Put the dongle in its bootloader first

The dongle's firmware is USB-HID only — it has no serial console — so while it runs normally there is no port for this page to open. Holding BOOT while you tap RESET starts the chip's ROM bootloader instead, which does present a port. This is the same step the command-line flasher needs.

  1. 1 Plug the dongle into USB. Directly, not through an unpowered hub.
  2. 2 Hold BOOT down. Keep holding it for the next step.
  3. 3 Tap RESET, then let go of BOOT. The dongle is now waiting, with its lights off.
  4. 4 Pick the port below and flash. On macOS it looks like cu.usbmodem…; on Windows it is a COM port.
