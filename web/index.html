Driver station

Pair gamepads to robots, enable the field, cap the speed, and trim the ESC neutrals. This is the page used at competition.

Robot code

Read main.py off a robot, edit it, and push it back. Also shows the saved neutrals — which quietly override whatever main.py says — and can put MicroPython on a brand-new board.

  • Robot on USB, not the dongle

Dongle firmware

Write the current dongle build over USB. Needed after a protocol change, or on a dongle that has never been flashed.

  • Dongle on USB
  • Hold BOOT, tap RESET first

Open flasher

Chrome or Edge, over HTTPS. The tools reach USB through WebHID and Web Serial, which Safari and Firefox do not implement. You grant each device once, per browser — after that the driver station reconnects on its own.

The command-line path still works and is the offline fallback: scripts/flash-robot.sh and scripts/flash-dongle.sh in the minibots-2026 repository.
